# FlexRIC and OpenAirInterface5G CVE Advisories

This repository contains public advisory pages for CVE IDs assigned for
vulnerabilities in FlexRIC and OpenAirInterface5G.

The advisories are written to satisfy the CVE public reference requirements:
each page identifies the affected product, affected version range, vulnerable
component, vulnerability type, attack vector, impact, and a technical summary
specific to that vulnerability.
